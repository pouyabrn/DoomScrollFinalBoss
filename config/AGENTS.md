# Configuration rules

- Files here are public defaults. Never put credentials, recipient addresses, private X accounts, or private topic preferences here.
- Every source needs a stable `id`, an HTTPS URL, a trust tier, a bounded item limit, and a terms/usage note.
- Sitemap adapters may read URL and `lastmod` metadata only. Page-body extraction needs a separate legal and technical review.
- Disable broken or legally ambiguous sources instead of adding a scraping workaround.
- Keep primary publishers above commentary and press in trust weighting.
- Source additions require a parser fixture or a documented live validation result.
